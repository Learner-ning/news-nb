# 🌳 新闻知识树（news-tree）

一个像**知识大树**一样生长的新闻聚合项目：

> **枝干 = 新闻分类，枝叶 = 不同厂家的新闻模块。**

侧栏是整棵树的导航：点「全部新闻」看整棵树，点一个枝干看一个分类，点一片枝叶只看那一个厂家的新闻；正文里每个厂家模块都可以独立展开/收起。

## 运行

```bash
npm install
npm start        # 或 npm run dev（文件变更自动重启）
```

打开 http://localhost:3000

## 树形结构

```
🌳 全部新闻
├── 🌐 综合          ← 枝干（分类）
│   ├── Google News 中文   ← 枝叶（厂家新闻模块）
│   ├── 新华社
│   └── 中国新闻网
├── 🔬 科技
│   ├── 36氪 / IT之家 / 爱范儿 / 极客公园 / 钛媒体
├── 📱 数码
│   └── 少数派
└── 📈 财经
    ├── 华尔街见闻 / 雪球 / 新浪财经
```

- 每个枝叶前有状态点：🟢 正常 · 🟠 回退到旧缓存 · 🔴 首次抓取失败
- 每个枝叶只显示自己的新闻（互不混流），点击新闻卡片进入站内详情页
- 浏览器前进/后退支持 `/detail/:id` 路由

## 怎么加一片新枝叶（新厂家）

只需编辑 [src/sources.js](src/sources.js)，在对应分类的 `sources` 数组里加一项：

```js
{
  id: "my-vendor",            // 唯一 id
  name: "我的厂家",           // 枝叶名称
  feed: "https://example.com/feed.xml", // RSS 地址
  note: "一句话介绍"          // 可选
}
```

保存后刷新页面，树、列表、详情会自动出现新模块，无需改任何其他代码。新增分类同理，在 `CATEGORIES` 里加一个枝干即可。

## API

| 接口 | 说明 |
| --- | --- |
| `GET /api/sources` | 整棵树：分类 + 厂家模块 + 实时状态（正常/休眠/条数） |
| `GET /api/news` | 全部新闻（每厂家最多 15 条） |
| `GET /api/news?source=ithome` | 只看某一片枝叶（一个厂家） |
| `GET /api/news?category=tech` | 只看某一个枝干（一个分类） |
| `GET /api/news/:id` | 单条详情（走缓存） |
| `GET /api/health` | 健康检查 |

## 整改记录（v2.0）

1. **修复静态资源 404**：静态文件移入 `public/`，修正 `express.static` 与兜底路由的路径。
2. **修复 Express 5 通配符崩溃**：`app.get("*")` 在 Express 5 已失效，改用 `app.use` 兜底 SPA 路由。
3. **按厂家模块化**：新增 [src/sources.js](src/sources.js) 厂家注册表，树、列表、详情全部由它驱动，新增厂家只改一个文件。
4. **知识树 UI**：侧栏树形导航 + 正文按「分类枝干 → 厂家枝叶」分模块展示，枝叶可独立展开收起。
5. **列表缓存**：每个厂家 5 分钟缓存 + 并发去重 + 抓取失败回退旧缓存，不再每次请求都打 RSS。
6. **安全加固**：外链只允许 http/https，前端统一转义 HTML，避免注入与危险协议。
7. **详情不再重复抓全量源**：`/api/news/:id` 直接复用缓存数据。

## 说明

- 部分厂家（如 36氪、Google News）RSS 可能因站点反爬或网络环境失效，服务端会记录日志并回退旧缓存，页面不会白屏。
- RSS 仅用于个人学习与信息聚合，生产环境请使用获授权的新闻 API，并遵守各网站的服务条款。
## 中央大树交互视图

页面默认进入「树形视图」：中央是一棵 SVG 知识大树，**枝干 = 分类，枝叶 = 厂家**。

- **鼠标滑到枝叶上**：该厂家的新闻从右侧面板浮出；
- **点击枝叶 / 枝干**：固定显示该厂家 / 该分类的新闻；
- **右下角「新闻显示方式」**（可切换，记住选择）：
  - `固定显示`：选中后新闻长时间停留在面板上；
  - `悬停显示`：只有鼠标滑到枝叶上时才显示，移开即收起；
- 顶栏可在「树形视图 / 列表视图」之间切换，列表视图保留原分类模块式浏览。

## 沉浸式粒子新闻树（/immersive）

顶栏点击「🌌 沉浸探索」或直接访问 `/immersive/` 进入全屏沉浸页：

- **中央粒子树**：Three.js/WebGL 粒子树（数千粒子，GPU 着色器驱动流动、呼吸与微动），树干=新闻系统，枝干=分类（科技/财经/社会/国际/娱乐/体育/生活），细枝=分支，每片枝叶=一条新闻；
- **重要新闻**：通过粒子数量、亮度、大小与运动幅度区分；
- **悬停交互**：鼠标靠近枝叶 → 粒子变亮、扩散、光晕，新闻卡片在枝叶旁弹出（标题/分类/时间/来源/摘要/详情入口）；
- **显示方式（右下角）**：`固定`（保持显示，选择其他枝叶时切换）/ `跟随`（移开鼠标自动隐藏）；
- **昼夜切换（左下角）**：黑夜草原 ↔ 白天草原平滑过渡（天空渐变、星辰淡出、日月云、雾与粒子颜色联动）；
- **背景设置（右上角 ⚙）**：默认黑夜草原 / 默认白天草原 / 自定义图片 / 纯色 / 视频背景（接口预留），背景修改不破坏粒子树；
- **数据层**：模拟数据位于 `public/immersive/data/news.json`，字段含 id/category/title/summary/source/time/importance/branch/leaf；接入真实 API 时替换 `public/immersive/js/news-data.js` 中的 `loadNews` 即可（已提供 `loadNewsFromAPI`）。

模块划分：`config / news-data / tree / background / daynight / interaction / ui / main`，粒子树全部走 GPU 着色器，DPR 上限 2，支持桌面鼠标与移动端触摸。
