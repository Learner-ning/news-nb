# NewsNow Bold

一个受 NewsNow 信息聚合思路启发的大胆、简洁、响应式新闻聚合站。

## 运行
1. 安装 Node.js 20+
2. `npm install`
3. `npm start`
4. 浏览器打开 `http://localhost:3000`

## 功能
- RSS 新闻聚合后端（Google News / 36氪 / 少数派）
- **点击新闻卡片进入站内详情页**（标题、摘要/正文、来源、时间）
- 详情页可一键「阅读原文」跳转外部链接，或复制链接
- 综合 / 科技 / 数码筛选
- 浏览器前进/后退支持详情页路由 `/detail/:id`
- 自动适配手机与电脑
- 简洁大胆的 NOW UI
- 前端与后端分离，后续可继续增加新闻源、缓存、搜索、收藏、AI摘要等

## 技术说明
- 后端：Express + rss-parser
- 每条新闻生成稳定 id（url 的 sha1 前 12 位）
- 列表缓存 + 详情 API `/api/news/:id` 双重保障

注意：新闻源的 RSS 地址可能因第三方站点调整而失效，生产环境建议替换为稳定且获授权的新闻 API/RSS。
